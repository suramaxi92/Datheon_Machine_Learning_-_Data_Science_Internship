This repository contains projects completed as part of the **Datheon Machine Learning & Data Science Internship**.

The projects demonstrate practical implementation of data analysis, machine learning algorithms, model evaluation, and data visualization using Python.

## 📂 Projects

### Task 1: Multi-Class Benchmark Classification Pipeline

**Dataset:** Iris Dataset

**Objective:** Build and compare multiple machine learning classification models to predict the species of Iris flowers.

**Technologies Used:**
- Python
- Pandas & NumPy
- Matplotlib & Seaborn
- Scikit-learn
- Google Colab / Jupyter Notebook

**Implementation:**
- Dataset loading and exploratory data analysis (EDA)
- Pairplot visualization
- Feature scaling using StandardScaler
- 80:20 train-test split
- Logistic Regression classification
- Decision Tree classification
- Model evaluation using Accuracy, Precision, Recall, and F1-score
- Confusion matrix heatmaps
- Model performance comparison
- Decision boundary visualization

**Model Performance:**

| Model | Accuracy |
|---|---:|
| Logistic Regression | 93.3% |
| Decision Tree | 96.7% |

**Result:** Decision Tree achieved the highest accuracy of 96.7% on the test dataset.

**Project File:** `Task-1_Iris-Classification/iris_classification_benchmark.ipynb`
